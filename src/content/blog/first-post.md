# Welcome to My Blog! 👋

This is my first blog post built with **Astro**, **TypeScript**, **Markdown**, and **TailwindCSS**.

## Why Astro?

Astro is an all-in-one web framework for building fast, content-focused websites. Here are some key benefits:

- **Zero JS by default**: Astro renders HTML on the server and strips away any remaining JavaScript
- **Islands Architecture**: Mix static and dynamic components seamlessly
- **Content Collections**: Type-safe markdown content management
- **Framework agnostic**: Use React, Vue, Svelte, or plain HTML components

## Tech Stack

This blog is built with:
- 🚀 Astro 6
- 📝 TypeScript
- 🎨 TailwindCSS
- 📄 Markdown
